- **B. 우측 하단 ↑ 미니 FAB**

  - 호버 시 accent 강조
  - `requestAnimationFrame` 기반 throttle, `passive` 스크롤 리스너

### 2. 알림 진입점 영구화 (인스타 ❤️ 패턴)
- 기존 `<span id="nav-notif-badge" display:none>` → **`<button id="nav-notif">` + 와이어 종 SVG + 빨간 점/카운트**
- **항상 표시**: 미읽음 0이어도 회색 종이 그대로 보임 (예전 문제: 모두 읽으면 진입점 사라짐)
- 미읽음 있을 때만 우상단에 빨간 점 + 카운트 (1-9, 9+로 캡)
- 호버 시 배경 옅게 + accent 컬러 강조
- `.nav-icon-btn` + `.nav-notif-dot` CSS + 모바일 반응형
- `updateNavBadges()` 재작성: 아이콘 영구 유지, 카운트만 토글

### 3. 알림 페이지 인스타화
- **페이지 진입 시 자동 일괄 읽음 처리** (`/notifications/read?ids=[]`) → 뱃지 즉시 0
  - 카드 자체의 "안 읽음" 시각화는 유지 (warm-glow + accent 보더 + 우측 dot)
  - "안 읽음 필터" 클릭 시에는 자동 읽음 스킵 (`skipMarkRead=true`)
- **날짜별 그룹화** — `groupNotifByDate()`로 오늘/어제/이번 주/이전 4구간 분류 + 섹션 헤더 (`오늘 · 3건`)
- **타입별 컬러 아이콘 뱃지** (아바타 우하단 오버레이):
  - 💬 댓글 (파랑 #38bdf8)
  - @ 멘션 (보라 #8b5cf6)
  - 🎯 퀘스트 (accent→red 그라데이션)
  - ❤️ 좋아요 (빨강 #ef4444)
  - 🔔 시스템 (그린 #4ade80)
- **모바일 더보기 메뉴 최상단에 "🔔 알림" 항목 추가** (로그인 상태일 때)
- **빈 상태 메시지 친근하게 개선** ("아직 알림이 없어요. 다른 사용자와 활발히 소통해보세요!" 등)

### 4. 좋아요 받음 알림 + like_received XP (P2 미구현 항목 동시 처리)
- **백엔드 SNS `toggle_like` INSERT 분기 확장**:
  - 작성자에게 `type='reaction'` 알림 생성 (title: "{actor}님이 회원님의 글을 좋아합니다", body: 이모지)
  - **같은 actor+post 알림 단일 유지**: INSERT 전 DELETE → 토글/리액션 변경 반복 시 누적 방지
  - `grant_xp(+2, 'like_received', ref_id=post_id)` — ref_id 중복방지로 **게시글당 1회만** 부여 (어뷰징 차단)
  - 자기 자신 글에는 알림/XP 모두 skip
- **프론트엔드 추가**:
  - `_notifTypeIcon`에 `reaction` 케이스 (빨간 ❤️ 미니 뱃지)
  - `renderNotifPageItem`에 verb "좋아합니다" 매핑 + reaction은 body 이모지를 큰 글씨로 강조
  - `showNotificationPopup` verb 매핑에도 추가
- **검증 시나리오** (모두 PASS):
  - 첫 좋아요 → 알림 생성 + XP +2 ✓
  - 좋아요 취소 → 알림 유지 (인스타 동작) ✓
  - 다른 리액션으로 변경 → 알림 1개만 유지·body 갱신·XP 추가 X ✓
