### 2. XP 시스템 종합 보완
- `ACTION_XP` 갱신: `comment_created +3` / `comment_received +3` 신설, `boss_raid_joined`/`first_zone_report`는 예약(주석)으로 분리
- `DAILY_CAP = {"comment_created": 5}` — `grant_xp()`에 일일 한도 검사 로직 추가
- SNS `add_comment`:
  - 게시글 작성자에게 `comment_received +3` (ref_id=post_id, 게시글당 1회)
  - 댓글 작성자에게 `comment_created +3` (ref_id=cid, 일일 5회 한도)
  - admin은 `comment_created` 부여 안 함
  - 자기 글 자기 댓글은 양쪽 모두 skip
- GIS `update_zone_location`: 인증 추가 + `grant_xp(reason='zone_fix', ref_id=zone.id)` — zone당 1회만 부여 (어뷰징 차단). 프론트엔드의 별도 `/ranking/add-xp` 호출 제거
- 라이브 검증: 댓글 받음/작성/일일 한도/zone_fix 어뷰징 모두 PASS

### 3. 트렌드 차트 4종 XP 기반 통합 + 시간 decay
- 점수 공식: `engagement_xp × 24 / (24 + age_hours)` (24h 절반 / 72h 1/4)
- **급상승 피드** (`trending_feeds`): `SUM(point_ledger.delta WHERE ref_id=post.id AND reason IN ('like_received','comment_received'))` × decay
- **인기 키워드** (`trending_hashtags`): CTE로 게시글별 decayed_xp 계산 후 해시태그별 SUM
- **인기 퀘스트** (`popular_quests`): `(recent_members×5 + recent_posts×3) × 24/(24+last_activity_h)` — 7일 활동량 + 시간 감쇄
- DB 인덱스: `idx_ledger_ref_reason ON point_ledger(ref_id, reason) WHERE ref_id IS NOT NULL`
- 도움말 트렌드 선정 기준 4종 모두 갱신

### 4. 게시글 수정 시 이미지 추가/삭제

## 주의사항
- `notifications.type` 값: `comment`, `mention`, `reaction`, `quest_invite`, `zone_alert`, `system`
- `point_ledger.reason` 값: `post_create`, `report_created`, `quest_post`, `cleanup_verified`, `comment_created`, `comment_received`, `like_received`, `zone_fix` (예약: `boss_raid_joined`, `first_zone_report`)
- admin 정책: 트렌드 피드/키워드/퀘스트는 노출(🛡️ 배지), 랭커는 제외, 댓글 작성 XP는 면제
- 트렌드 점수의 engagement_xp는 ledger 누적값 — 옛 댓글/좋아요(XP 도입 전)는 합산되지 않으니 표시상 좋아요/댓글 수와 일치하지 않을 수 있음
- 캐시 키: `trending_feeds_{all|general|report}` 3종 분리 — `invalidate(prefix=True)`로 일괄 무효화
- 게이트웨이는 main 디렉토리에서 실행 — worktree 작업 시 파일 복사 잊지 말 것
