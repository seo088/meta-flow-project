### 1. 시스템 메시지 DM/알림 분리
- 백엔드 SNS: `POST /notifications/system` 신규 (type, title, body, ref_id, recipients[])
  - 허용 타입: `quest_invite`, `zone_alert`, `system`
  - 자기 자신 제외, 최대 50명 일괄 전송
  - `notifications` 테이블 재활용 (ref_post_id = quest_id 등)
- `/messages/conversations`, `/messages/with/{username}`, `/messages/unread-count`
  - 시스템 프리픽스(`[QUEST_INVITE`, `[ZONE_FIX`) 메시지 필터링
- 프론트엔드:
  - `sendQuestInviteDm` → `/notifications/system` 호출로 변경 (DM 미생성)
  - 알림 팝업에 `quest_invite` 타입 카드 렌더링 (참여/나중에 버튼)
  - `acceptQuestInvite`, `dismissNotif` 함수 추가

### 2. Gemini API 이모지 추천
- AI 서비스: `POST /predictions/emoji_suggest`
  - 모델: `gemini-flash-latest` (env: GEMINI_MODEL로 override 가능)
  - thinking 비활성화 (`thinkingConfig.thinkingBudget=0`) — 토큰 절약
  - 응답 parts 합치고 정규식으로 이모지만 추출 (JSON 폴백 포함)
  - 키 없거나 실패 시 키워드 기반 폴백 (15개 패턴, 기본 이모지)
- 프론트엔드:
  - 게시글 컴포즈: 본문 textarea 아래 "🤖 이모지 추천" 버튼
  - 댓글 입력: 작은 🤖 버튼 (등록 버튼 옆)
  - `suggestEmojisForTextarea(inputId, rowId)`, `insertEmojiInto(inputId, emoji)`
  - 추천 결과는 클릭 시 커서 위치에 삽입

### 3. 시스템 모니터링 차트 개선
- SVG 기반 차트 헬퍼 2종 추가:
  - `renderTTLChart(tiers, act)` — 적응형 TTL 분포, 활성 단계 하이라이트 + 그리드 + Y축%
  - `renderDailyChart(days, avg)` — 일별 접속 막대, 평균선(녹색 점선), 주말 빨강 강조, hover title
- 카드 배경(var(--bg-tertiary)) + 내부 패널(var(--bg-secondary)) + dashed 그리드
- 막대 그라데이션 (linearGradient `dailyGrad`)
