# ADR-001: 단일 파일 SPA 아키텍처

**상태**: 채택  
**일자**: 2026-03-01  

## 결정
프론트엔드를 `index.html` 단일 파일로 구현한다 (빌드 도구 없음).

## 이유
- 군산대학교 연구 프로젝트로, 빠른 프로토타이핑이 최우선
- React/Vue 빌드 파이프라인 없이 즉시 수정·배포 가능
- 학생 참여자가 빌드 도구 학습 없이 참여 가능

## 트레이드오프
- 파일 크기가 커짐 (5000줄+)
- 코드 분리/모듈화 제한
- JS 구문 오류 시 전체 앱 중단 → 수정 후 반드시 구문 검증 필수

## 적용 규칙
- 수정 후 `node -e` JS 구문 검증 필수 (CLAUDE.md 규칙 6.1)
